前回のメインAsset IDを記憶する修正版

適用手順
1. ビューアを完全に閉じます。
2. 現在の index.html / app.js / style.css をバックアップします。
3. ZIP内の3ファイルをcesium-app直下へ上書きします。
4. 起動.batで再起動します。

使い方
1. メインAsset IDへ任意のIDを入力します。
2. 「読込」を押します。
3. 読込に成功したIDが保存されます。
4. 次回起動時は保存したIDをメインAssetとして自動読込します。

初回または保存値がない場合のみconfig.jsのMAIN_ASSET_IDを使用します。
ブラウザー/Electronのサイトデータを削除すると保存値も消えます。
